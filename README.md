# 🎬 MovieMate AI

An explainable hybrid movie recommendation system built with MovieLens and TMDB data.

## Project Goal

MovieMate AI helps users discover movies through personalized recommendations.
The final system will combine content-based filtering, collaborative filtering,
and hybrid ranking.

## Project Status

🚧 In progress — Phase 1: Data Foundation

## Planned Features

- Content-based movie recommendations
- Collaborative filtering using user ratings
- Hybrid recommendation ranking
- Streamlit web application
- Movie search and filters
- Recommendation evaluation with Precision@K and Recall@K

## Dataset

- [MovieLens 25M](https://grouplens.org/datasets/movielens/25m/)
- TMDB metadata (to be integrated later)

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Streamlit
